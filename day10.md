## Objective
Build a personal portfolio website using AI assistance.

## What I Built
Created a responsive portfolio website showcasing my introduction, skills, projects, coding journey, and contact information.

## Features
- About Me section
- Skills and Tools section
- Projects showcase
- LeetCode journey highlight
- Contact information
- Clean and simple design

## Technologies Used
- HTML
- CSS
- JavaScript
- Claude AI

## Learning Outcomes
- Learned how to use AI tools to generate website structures.
- Improved understanding of organizing content for a portfolio.
- Practiced customizing AI-generated code.
- Learned how to document and upload projects on GitHub.

## Challenges Faced
- Deciding what information to include in the portfolio.
- Customizing project descriptions and skills.
- Organizing files properly before uploading to GitHub.
