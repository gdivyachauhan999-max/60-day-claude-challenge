# Day 51 – Product Discovery & Sprint Planning

## Overview

Today, I completed the Product Discovery & Sprint Planning phase of my 10-Day Full-Stack Capstone Project as part of the AB Talks 60-Day Claude AI Challenge.

---

# Finalized Project

## Project Name

### PrepAI (Working Title)

PrepAI is an AI-powered Mock Interview Platform designed to help students and aspiring developers prepare for technical interviews through AI-generated questions and
structured feedback.

The platform enables users to:

- Register and log in securely.
- Choose an interview domain.
- Attempt AI-generated mock interview questions.
- Receive AI-generated feedback instantly.
- Track their performance over time.
- Review their previous interview sessions.

This project has been intentionally scoped for a 10-day development timeline while maintaining industry-level architecture and best practices.

---

# Project Objective

The objective of PrepAI is to provide an affordable and accessible mock interview experience for students and developers preparing for internships, placements, 
and technical interviews.

The platform focuses on helping users:

- Improve technical interview skills.
- Practice consistently.
- Identify strengths and weaknesses.
- Receive actionable feedback.
- Monitor progress over time.

# AI Feedback System

The AI feedback module will provide:

- Interview Score
- Strengths
- Weaknesses
- One Practical Improvement Suggestion

This feedback system has been intentionally designed to provide meaningful insights while keeping the implementation realistic for a 10-day capstone project.

## Excluded Features

The following features have been intentionally excluded to avoid scope creep:

- Video Interviews
- Voice Recognition
- Real-Time Multiplayer Interviews
- Payment Gateway
- Native Mobile Application
- Admin Dashboard
- Social Features and Leaderboards

These features can be considered for future versions of the project.
