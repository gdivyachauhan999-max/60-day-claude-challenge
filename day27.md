# Day 27 – Prior Authorization Story Simulator

## Objective
Built an interactive Prior Authorization Story Simulator using HTML. The application demonstrates the complete healthcare prior authorization workflow through Rahul's journey, with explanations from Priya at every stage.

## Features
- Interactive story-based simulator
- 8 story chapters
- Two decision options after each scene
- Progress bar to track journey
- Rahul's healthcare workflow
- Priya's explanations at every stage
- Final approval process
- Restart option to explore different dialogue paths
- Responsive HTML application

## What I Learned
- Understood the complete Prior Authorization workflow.
- Learned how insurance providers review authorization requests.
- Explored the roles of patients, healthcare providers, and insurance companies.
- Improved my understanding of interactive storytelling in web development.
- Learned how decision-based user interactions enhance user experience.
- Practiced organizing an HTML project and documenting the work professionally.

## Technologies Used
- HTML
- CSS
- JavaScript

## Outcome
Successfully completed the Prior Authorization Story Simulator and explored multiple dialogue paths while understanding the healthcare authorization process.
