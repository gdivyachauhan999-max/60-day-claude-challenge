# Day 39 – PDF Splitter & Merger using Claude AI

## Task Objective

The goal of today's task was to build a complete browser-based PDF Splitter & Merger application using Claude AI.
The application should allow users to split PDF files into separate documents, merge multiple PDFs into one, preview files before processing, and download the processed PDFs. 
All processing must happen locally in the browser to ensure user privacy.

---

## Resources Used

- Task Resources (Provided)
- Solution Video
- Claude AI
- PDF-Lib
- PDF.js
- HTML5
- CSS3
- JavaScript

---

## Development Process

- Read all the provided resources carefully.
- Watched the solution video to understand the workflow.
- Opened Claude AI and set the effort level to **Low**.
- Started a new conversation.
- Pasted the provided **PDF Splitter & Merger Prompt**.
- Answered Claude's interview questions regarding the application requirements.
- Generated a complete single-file HTML application.
- Saved the generated HTML file locally.
- Opened the application in the browser.
- Tested both the PDF Splitter and PDF Merger functionalities.
- Verified preview and download features.
- Captured screenshots of every important stage.
- Uploaded all required files to the GitHub repository.

---

## Features Implemented

### PDF Splitter
- Upload PDF using Drag & Drop or File Picker
- Page Preview
- Custom Page Range Selection
- Split After Selected Pages
- Extract Specific Pages
- Download Split PDF

### PDF Merger
- Upload Multiple PDF Files
- Arrange Merge Order
- Merge PDFs into a Single File
- Download Merged PDF

### Additional Features
- Responsive User Interface
- Clean & Modern Design
- Client-side Processing
- No Server Upload Required
- Fast PDF Processing
- Privacy Focused
