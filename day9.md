# Day 9 - Build & Enhance an AI Nutrition Analytics App

## Project Overview

In this project, I developed **NutriScope**, an AI-powered Nutrition Analytics application using Claude AI.
The application was built in two stages: an MVP version and an enhanced version.
This activity helped me understand how iterative prompting can improve an application's functionality and user experience.

---

## Files Included

[nutriscope_mvp.html](https://github.com/user-attachments/files/28746504/nutriscope_mvp.html) - MVP version of the application generated using Prompt 1.
[nutriscope_enhanced.html](https://github.com/user-attachments/files/28746372/nutriscope_enhanced.html) - Enhanced version of the application generated using Prompt 2.

---

## MVP Version Features

- User profile section
- Age input field
- Gender selection
- Height and weight inputs
- Activity level selection
- Dietary preference selection
- Basic nutrition target generation
- Simple navigation system

---

## Enhanced Version Features

- All MVP functionalities included
- Added **Health Goal** selection
- Added **Meal Planner** section
- Added **Risk Analysis** section
- Improved **Recommendations** module
- Educational disclaimer for responsible usage
- Enhanced navigation experience
- Better nutrition planning support

---

## Comparison Between MVP and Enhanced Versions

| MVP Version | Enhanced Version |
|-------------|------------------|
| Basic user profile inputs | Additional health goal input |
| Simple nutrition tracking | Comprehensive nutrition planning |
| Limited navigation options | Meal Planner and Risk Analysis sections |
| Basic recommendation system | Improved recommendation module |
| Minimal functionality | More advanced and user-friendly features |
| No disclaimer section | Included educational disclaimer |
