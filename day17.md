# Day 17 – AI Vehicle Cost & Fuel Analysis Dashboard

## Project Overview
Built an AI-powered Vehicle Cost & Fuel Analysis Dashboard using Claude and a provided vehicle dataset. The dashboard analyzes fuel efficiency,
maintenance costs, environmental impact, and E85 fuel economics through interactive visualizations and KPI cards.

## Vehicle Details
- Vehicle: Ford Endeavour
- Fuel Type: Diesel
- Usage: Mixed
- Vehicle Age: 5 Years
- Monthly Distance: 1250 km

## Tasks Performed
- Downloaded and explored the vehicle dataset.
- Uploaded the dataset to Claude.
- Used prompt engineering to generate a complete HTML dashboard.
- Analyzed fuel cost, maintenance cost, and CO₂ emissions.
- Evaluated E85 economics and break-even calculations.
- Generated interactive charts and KPI metrics.
- Saved and tested the dashboard in a browser.

## Key Findings
1. Diesel fuel showed a running cost of approximately ₹4.67/km, making it more economical than Petrol and E85.
2. EV had the lowest cost per kilometer and the lowest CO₂ emissions among all fuel types.
3. E85 fuel had lower pump prices but higher running costs due to reduced mileage efficiency.
4. Maintenance costs generally increased with vehicle age.
5. CNG provided a strong balance between affordability and environmental impact.
6. The dashboard enabled quick comparison of fuel options using visual analytics.

## Dashboard Insights
### Cost per Kilometer
- CNG: ₹3.33/km
- Diesel: ₹4.67/km
- EV: ₹1.75/km
- Petrol: ₹6.15/km
- E85: ₹6.37/km

### E85 Analysis
- Pump Saving: 18.0%
- Running Cost Penalty: 3.6%
- Break-even Price: ₹79.11/L
- E85 Score: 5.7/10

### Environmental Impact
- EV recorded the lowest CO₂ emissions.
- E85 performed well environmentally but was less attractive economically.

## Learnings
- Learned how to transform raw datasets into meaningful business insights.
- Improved prompt engineering skills using Claude.
- Learned to generate complete HTML dashboards using AI.
- Understood fuel-cost comparison and vehicle economics analysis.
- Practiced data visualization using SVG charts and KPI cards.
- Learned how AI can automate dashboard creation from structured datasets.

## Conclusion
This project demonstrated how AI can rapidly convert structured vehicle data into an interactive dashboard, helping users evaluate fuel choices,
operating costs, maintenance expenses, and environmental impact more effectively.
