## Day 33 – Media Integrity Analyzer

## 📌 Overview
Today, I built and explored the Media Integrity Analyzer, an interactive HTML application generated using Claude AI.
The application helps users identify misleading headlines, emotional manipulation, and media bias through hands-on challenges.

## 🎯 Objectives

-Understand how misleading headlines influence readers.
-Detect emotional manipulation in online content.
-Analyze media integrity using interactive scenarios.
-Learn to verify information before reacting or sharing.

## 🛠️ Features

-🎯 Headline Detective Challenge
-📰 Headline Accuracy Analysis
-❤️ Emotion Detector Challenge
-📊 Live Media Integrity Metrics
-📈 Final Media Integrity Dashboard
-🔄 Replay with Randomized Scenarios
-🎨 Custom Theme Selection

## 📚 Key Learnings

-Headlines can exaggerate facts to attract attention.
-Emotional language influences how people react before they verify information.
-Fear, urgency, curiosity, and engagement bait are common manipulation techniques.
-Reading beyond the headline helps avoid misinformation.
-Media literacy is essential for making informed decisions online.

## 🔍 Challenge Results
-Headline Accuracy: 34%
-Source Reliability: 27%
-Emotional Manipulation: 65%
-Audience Targeting: 84%
-Overall Media Integrity Score: 38

## 💡 Reflection

This project improved my understanding of media literacy by showing how headlines and social media posts can use emotional manipulation to influence readers.
It reinforced the importance of fact-checking, reading complete articles, and critically evaluating online content before sharing it.
