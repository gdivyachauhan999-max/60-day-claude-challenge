## Day 20 - Face Puzzle Game

## Objective

The objective of this task was to use Claude AI to generate a fully functional Face Puzzle Game web application using HTML, CSS, and JavaScript.
The application allows users to capture an image through their webcam, convert it into puzzle pieces, and solve the puzzle while tracking performance metrics.

## Task Performed

1. Application Generation

- Opened Claude AI and started a new conversation.
- Used the provided Face Puzzle Game prompt.
- Generated a complete HTML application.
- Saved the generated code as an HTML file.

2. Application Testing

- Opened the HTML file in a web browser.
- Granted webcam permissions.
- Captured an image using the camera.
- Successfully loaded the image into the puzzle game.

3. Difficulty Testing

Tested all available difficulty levels:

- 3×3 Grid (Easy)
- 4×4 Grid (Medium)
- 5×5 Grid (Hard)

4. Feature Validation

Verified the following features:

- Webcam image capture
- Puzzle generation from captured image
- Drag-and-drop functionality
- Touch interaction support
- Shuffle mechanism
- Timer functionality
- Move counter tracking
- Puzzle completion detection
- Leaderboard system

5. Gameplay Testing

- Solved puzzles across multiple difficulty levels.
- Confirmed smooth interaction and responsiveness.
- Verified accurate timer and move tracking.
- Checked leaderboard updates after puzzle completion.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Webcam API
- Drag and Drop API

## Key Learnings

- Learned how AI can generate complete web applications from detailed prompts.
- Gained hands-on experience with webcam integration in web applications.
- Understood image-based puzzle game logic.
- Explored drag-and-drop and touch event handling.
- Learned how timers and move counters can be implemented in JavaScript.
- Improved understanding of testing and validating application features.
- Experienced the workflow of generating, testing, documenting, and deploying AI-created applications.

## Features Implemented

- Real-time webcam capture
- Custom image puzzle generation
- Multiple difficulty levels
- Interactive drag-and-drop gameplay
- Mobile touch support
- Timer tracking
- Move counting
- Leaderboard management
- Responsive user interface

## Conclusion

Successfully generated, tested, and validated a complete Face Puzzle Game application using Claude AI.
All required features worked as expected, including webcam capture, puzzle generation, difficulty levels, 
drag-and-drop interactions, timer, move counter, and leaderboard functionality.
