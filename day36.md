# Day 36 – Cognitive Pattern Explorer

## Objective
The objective of this task was to build and explore a Cognitive Pattern Explorer web application using Claude AI.
The application helps users understand their thinking patterns and decision-making style through interactive scenarios, drag-and-drop activities, 
thinking timelines, and a personalized reflection journal.

## Tasks Completed
- Read the provided learning resources.
- Watched the solution video.
- Opened Claude AI.
- Set Claude effort level to Low.
- Started a new conversation.
- Pasted the provided Cognitive Pattern Explorer prompt.
- Generated the complete HTML application.
- Saved the generated HTML file.
- Opened the application in the browser.
- Selected Calm Mode and completed all activities.
- Completed Chapter 1 by answering all five scenarios.
- Completed Chapter 2 drag-and-drop categorization activity.
- Completed Chapter 3 thinking timeline activities.
- Reviewed the personalized Reflection Journal.
- Compared thinking tendencies across all chapters.
- Replayed the application in Stress Mode.
- Took screenshots of the Reflection Journal and Thinking Profile.
- Created the Day36 folder.
- Added the HTML file, screenshots, and day36.md to GitHub.
- Committed and pushed all changes successfully.

## Key Learnings
- Learned how AI can generate complete interactive HTML applications.
- Understood different cognitive and decision-making patterns.
- Explored how analytical, emotional, reflective, and action-first thinking influence decisions.
- Learned the importance of self-reflection through interactive assessments.
- Practiced working with drag-and-drop interfaces and thinking timeline activities.
- Gained experience documenting projects and uploading them to GitHub.

## Reflection
This activity helped me understand how different thinking styles influence everyday decisions. My reflection journal showed that my dominant thinking style is Analytical Thinker,
meaning I usually prefer analyzing situations, evaluating evidence, and making logical decisions before taking action. 
Completing both Calm Mode and Stress Mode also showed how the application presents the same assessment experience across different modes while encouraging self-reflection.
