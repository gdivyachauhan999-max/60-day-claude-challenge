# Day 48 - The Verdict Engine

## Task Name

The Verdict Engine - Cloud Provider Compare & Decide

## Project Overview

Today, I built an interactive HTML application using Claude AI that compares major cloud service providers based on multiple engineering-focused criteria.

The application allows users to:

- Compare AWS, Google Cloud, Microsoft Azure, and DigitalOcean.
- Assign custom priority weights to different criteria.
- View live ranking updates based on selected priorities.
- Review all data sources used for the comparison.
- Understand the complete research methodology and conflict resolution process.

## Features Implemented

- Live weighted ranking system.
- Interactive sliders for adjusting criteria weights.
- Real-time ranking updates.
- Criteria-wise provider comparison table.
- Sources panel containing all reference links.
- Detailed research methodology section.
- Preset configurations for different use cases.
- Reset button for equal weight distribution.

## Criteria Used

The comparison is based on the following five criteria:

1. Compute Pricing
2. Region / Availability Zone Footprint
3. Managed Kubernetes Maturity
4. Compute Uptime SLA
5. Egress Bandwidth Cost

## Providers Compared

- AWS
- Google Cloud
- Microsoft Azure
- DigitalOcean

## Testing Performed

I successfully tested the application by:

- Running the HTML file locally in the browser.
- Adjusting all criteria weights.
- Verifying that rankings update dynamically.
- Testing multiple weight combinations.
- Reviewing the provider comparison table.
- Checking all source links.
- Opening and reviewing the "How this was researched" section.

## Sources Panel Verification

All source links were successfully included for:

- Compute pricing
- Region and AZ information
- Managed Kubernetes maturity
- Compute uptime SLA
- Egress bandwidth costs

## Research Methodology Reviewed

The research section explains:

- Data collection methodology.
- Compute pricing normalization.
- Region and availability zone comparison.
- Kubernetes maturity evaluation.
- SLA comparisons.
- Egress bandwidth cost analysis.
- Conflict resolution between different sources.
- Difference between estimates and hard facts.

## Key Learnings

- Learned how AI can build transparent and explainable decision-making tools.
- Understood how weighted scoring systems work in real-world applications.
- Learned how live ranking algorithms can be implemented using HTML, CSS, and JavaScript.
- Explored source-backed research methodologies for cloud infrastructure comparisons.
- Understood the importance of documenting conflicts and assumptions in technical research.
- Learned how to create interactive standalone HTML applications using Claude AI.
- Improved my understanding of cloud provider comparison metrics.

## Conclusion

This project helped me understand how AI can be used to build transparent, data-driven decision support systems. The Verdict Engine provides an interactive and
research-backed approach to comparing cloud providers while allowing users to customize decision-making criteria in real time.
