# Day 44 – LinkedIn Profile Roast & Rebuild using Claude AI

## Objective
The objective of this task was to analyze an existing LinkedIn profile using Claude AI, identify weaknesses from a recruiter's perspective,
and generate a complete profile improvement report with actionable recommendations.

---

## Tools Used
- Claude AI
- HTML
- Web Browser
- Git & GitHub

---

## Task Workflow

1. Read the provided resources.
2. Watched the solution video.
3. Opened Claude AI.
4. Set the effort level to **Low**.
5. Started a new conversation.
6. Pasted the provided prompt.
7. Answered Claude's interview questions.
8. Generated the complete HTML application.
9. Saved the generated HTML file.
10. Opened the HTML file in the browser.
11. Tested the LinkedIn Profile Optimization workflow.
12. Captured screenshots.
13. Uploaded the HTML file, screenshots, and documentation to the Day44 folder.
14. Committed and pushed all changes to GitHub.

---

# Project Overview

The generated HTML application performs a detailed review of a LinkedIn profile and provides recruiter-style feedback.

The report includes:

- Profile Roast
- Detailed Scorecard
- LinkedIn Profile Rebuild
- Headline Suggestions
- About Section Rewrite
- Experience Rewrite
- Skills Recommendations
- Before vs After Comparison
- 7-Day LinkedIn Activation Plan
- Summary Card

---

# Key Insights

### Initial Profile Score
**34/100**

### Improved Profile Score
**78/100**

### Major Issues Identified

- Headline was not optimized for recruiter searches.
- About section lacked a strong introduction and impact.
- Experience section did not highlight projects effectively.
- Missing important technical keywords.
- Skills section required better recruiter-focused optimization.

---

# Improvements Suggested by Claude

- Created recruiter-friendly LinkedIn headlines.
- Completely rewrote the About section.
- Improved Experience section with stronger action-oriented descriptions.
- Recommended high-impact technical skills.
- Added SEO-friendly keywords for better recruiter visibility.
- Generated a 7-Day LinkedIn growth strategy.
